mathkit

Agentic-first math expression evaluation service

Go Single Binary No Database MCP GitHub

Quick Start

# Build and run make build && ./mathkit # Evaluate an expression curl "http://localhost:7100/eval?expr=2+3*4" # → expr=2+3*4 result=14 # Functions and constants curl "http://localhost:7100/eval?expr=sqrt(16)+pi" # → expr=sqrt(16)+pi result=7.141592653589793 # Factorial curl "http://localhost:7100/eval?expr=5!" # → expr=5! result=120 # Trig in degree mode curl "http://localhost:7100/eval?expr=sin(90)&mode=degree" # → result=1 # Variables curl "http://localhost:7100/eval?expr=x*y&x=3&y=4" # → result=12 # Batch evaluation curl "http://localhost:7100/eval/batch?expr=2+2&expr=3*3" # → expr=2+2 result=4 # → expr=3*3 result=9

Principles

Agent IS the Interface

No UI, no SDK. The API is the product.

Plain Text by Default

One labeled, grepable line per result. JSON on demand.

Instructive Errors

Every 4xx includes a hint for self-correction.

Self-Documenting

GET /help returns the full operating manual.

Single Binary

Go, CGO_ENABLED=0, zero external dependencies.

MCP Connector

Speaks Model Context Protocol at POST /mcp.
